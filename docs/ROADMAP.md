# Roadmap

## Implemented

- Secure TikTok opportunity scoring and deterministic production packs
- Versioned shared storage, non-destructive legacy migration, and atomic backups
- Plugin registry, feature flags, events, and provider contracts
- TikTok evidence, profiles, lifecycle, duplicates, batch intake, and testing plans
- Content Studio deterministic variants and optional AI adapter
- YouTube manual transcript/metadata import with provenance
- Pattern intelligence, DNA reports, and correlation-only analytics
- Projects, production status, performance entry, exports, and system health
- Automated unit, migration, storage, security, export, and workflow tests

## Next releases

1. Calendar and campaign assignment interfaces
2. Compliance review center and versioned rule packs
3. Rich variant history, locks, favorites, and side-by-side comparison UI
4. Source/passport library and research-report exports
5. Optional IndexedDB adapter for larger transcript and performance datasets
6. Browser-driven accessibility and end-to-end regression suite
7. Optional provider integrations, each disabled by default

No roadmap item may create a mandatory server or fabricate live platform data.
