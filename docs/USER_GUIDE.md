# User guide

## Start

Open `index.html` directly, or run `node tools/serve.js` and visit `http://localhost:4173`. No account, API key, installation, or network service is required.

## Workbench

Enter known product evidence and leave unknown fields blank. Generate a production pack, inspect confidence and claim risks, save it to the local Library, or export CSV, Markdown, JSON, and print output.

## Content Studio

Enter a subject, benefit, audience, platform, and tone. The app generates a deterministic offline draft and saves it in the shared local database. Generated drafts are inferred; verify every factual statement.

## YouTube Research

Paste a YouTube URL, optional observed title, and transcript. The app does not scrape or download the video. It stores manual provenance, opening candidates, basic text structure, and explicit analysis limitations.

## Operations

Create projects, advance them through the production queue, and record observed views and conversions. Workflow history is retained. Analytics are descriptive and never establish causation.

## Backups

In Library, select **Full backup** to export local TikTok records. Restore accepts only validated backups produced by the app, rejects unknown keys and oversized files, and rolls back partial writes.

## Privacy

Core workflows run locally. Browser storage remains on the device. Optional future providers must be configured separately.
